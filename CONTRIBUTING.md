# Contributing / المساهمة

Thanks for improving SQL Playground Local.

## Development
1. Use Python 3.10+ and create a virtual environment.
2. Install with `python -m pip install -e .`.
3. Run `python -m unittest discover -s tests -v` and `python -m compileall -q src tests`.
4. Keep runtime dependencies at zero unless a change has a strong justification.
5. Add or update tests for behavioral changes.
6. Keep user-facing documentation accurate in both English and Arabic where applicable.

Please keep pull requests focused, avoid committing database files or credentials, and explain security-sensitive changes clearly.

---

مرحبًا بالمساهمات. استخدم Python 3.10+، شغّل الاختبارات و`compileall` قبل الإرسال، أضف اختبارات للتغييرات السلوكية، ولا ترفع قواعد بيانات محلية أو أسرارًا أو بيانات شخصية. حافظ قدر الإمكان على عدم إضافة اعتماديات تشغيل خارجية وعلى دقة التوثيق الإنجليزي والعربي.
